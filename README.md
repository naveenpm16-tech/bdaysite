# Birthday Aneesa — Interactive GitHub Pages site

This version is rebuilt as real HTML/CSS/JavaScript. It does **not** use screenshots or a separate image for every scene.

The sequence is:
Happy Birthday → Yes → pop 4 balloons → candle → wish → bouquet → envelope → progressively typed letter → gift → final card → QR.

No mouse cursor is displayed (`cursor: none`) to keep the presentation close to the recording.

Upload the whole folder to a GitHub repository and enable Settings → Pages → Deploy from branch → main → /(root).
